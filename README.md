# Artimañas 2026

Esta rama contiene los archivos estáticos publicados con GitHub Pages.

- Fuente de Pages en la raíz de `gh-pages`.
- Sitio vigente en `2026/temporal/`.
- Enlace público https://0nicolas00.github.io/artimanas-landing/2026/temporal/
- Código editable en `trabajo/2026` y versión estable en `main`.

Para actualizar la publicación, compilar el código de trabajo y copiar `index.html`, `css/`, `js/` y `assets/` dentro de `2026/temporal/`, conservando las rutas relativas y `.nojekyll`.
